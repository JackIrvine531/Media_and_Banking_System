# Media_and_Banking_System
an application where users can search and buy records if they have the funds available in their bank account

## About
a application that reads in records from a database, populates a list with these records, which the user can buy if they have the required funds in their bank account.

## Features
- reading a database
- populating a list with objects created from the database
- searching through the list by filters or name
- creation of a bank account
- deposit or withdrawal of funds from the bank account
- if the user has the funds they can buy the record albums.

  ## Technologies
  - C#
